# AUTOTRADINGSYSTEM
This Python-based stock trading system uses Tkinter and yFinance to fetch real-time data, display price charts, and suggest buy/sell actions using basic strategies. It allows users to simulate trades, manage a virtual portfolio, and track transaction history—ideal for learning trading and GUI development.
A **desktop stock trading system** built with **Python**, **Tkinter**, and **yfinance API**. Users can fetch real-time stock data, get buy/sell suggestions based on simple strategies, maintain a virtual portfolio, and track transaction history. All trades are simulated for **educational purposes only**.

## Features
- Real-time stock price fetching using yfinance
- Buy/sell suggestions using multiple strategies
- Portfolio management (track owned stocks and purchase prices)
- Transaction history logging
- Interactive GUI with live graph of stock prices
- Easy-to-use interface with Tkinter

## Requirements
- Python 3.x
